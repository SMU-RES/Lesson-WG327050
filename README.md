本仓库收录课程设计题目、评分标准、课件，以及使用 8255A 和 8253 的键盘音调控制程序原稿。

- **课程代码**：`WG327050`

## 源码说明

程序从 8255A 的 PB 口读取按键，使用 PA 口输出按键状态，并配置 8253 计数器 2。硬件端口地址和时钟常量在源文件中定义。

源码保留原稿，其中 `MOV [bx],[1200h]` 是内存到内存的 `MOV` 语句，使用前需要核对；本次整理未修改程序逻辑。
